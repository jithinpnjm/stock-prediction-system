# ADR-001: Preserve 1m Data as the Source of Truth

Status: Accepted

The system retains 1-minute Bank Nifty SPOT data even though the primary model layer
uses canonical 5-minute candles.

Rationale:

- 1m data resolves intrabar barrier ordering better than 5m OHLC.
- 1m data supports microstructure-inside-5m research.
- 1m data provides better execution and data-quality diagnostics.
- Future feature experiments should not require re-downloading history.

The 5m model layer is therefore a derived representation, not the source of truth.
